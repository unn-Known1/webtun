# WebTun screenshots

Fresh screenshots of the current UI, captured on 2026-10-08.

- **Desktop:** 1440 × 900 pixels.
- **Mobile:** 390 × 844 pixels.
- **Component and workspace views:** default Light theme only, 43 captures per device.
- **Home tab:** all nine named themes, one capture per theme and device.
- **Total:** 104 PNG files.

Files follow `desktop-<component>-light.png` or
`mobile-<component>-light.png`. Home files follow
`<device>-home-launchpad-<theme>.png`.

Home themes: Light, Catppuccin Latte, Nord Light, Tokyo Night, Solarized Dark,
Gruvbox, Dracula, Monokai, and Midnight OLED. The System setting resolves to a
named theme rather than adding another palette.

Coverage includes settings sections, device sessions, explorer and selection,
context menus, file properties, creation/rename dialogs, confirmation dialogs,
system stats, SSH, listening ports, terminal sessions, notifications, command
history/library/composer, transfers, shortcuts, search, editor and draft views,
Git diff/hunks, Markdown/HTML/PDF previews, tab switching, overflow menus,
terminal search, terminal workspace, and the PIN screen.

Screenshots use a demo workspace and sample host, session, and transfer data.
